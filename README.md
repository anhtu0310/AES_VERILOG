# AES-128 encryptor in Verilog

Two synthesizable AES-128 encryption cores, a self-checking testbench and a
pure-Python reference model. The cores are also used as a memory-mapped
accelerator in the RV32I SoC of
[RISC-V-Pipeline-Verilog](https://github.com/anhtu0310/RISC-V-Pipeline-Verilog)
(`rtl/periph/aes_accel.v` there).

| Core | Latency | Throughput | Xilinx 7-series (Yosys) |
|------|---------|------------|-------------------------|
| `aes128_pipe` | 10 clocks | 1 block / clock | ~15.5k LUT, 3.9k FF |
| `aes128_iter` | 10 clocks | 1 block / 10 clocks | ~2.7k LUT, 0.56k FF |

The original design (in git history up to `c917910`, `Verilog/src/`) took
102 clocks per block and only worked in simulation; see
[`docs/AES.md`](docs/AES.md) for the review and what changed.

## Layout

```
Verilog/
  rtl/aes_functions.vh   SubBytes, ShiftRows, MixColumns, key expansion, round
  rtl/aes_sbox.vh        S-box table (generated by tools/aes_ref.py)
  rtl/aes128_pipe.v      10-stage pipeline, per-block key, tag, clock enable
  rtl/aes128_iter.v      one round per clock, valid/ready handshake
  tb/tb_aes.v            testbench for both cores
  tb/vectors_legacy.txt  the 100 vectors made by the original C++ model
  tools/aes_ref.py       reference model, vector and S-box generator
  Makefile
CPP/aes_encryption.cpp   original C++ model (vector generator)
```

## Interfaces

`aes128_pipe #(TAG_W)`: drive `in_valid`, `in_key`, `in_block`, `in_tag` in
any clock; ten clocks later `out_valid` is high with `out_block` and
`out_tag`. Each block carries its own key through the pipeline. `ce = 0`
freezes the whole pipeline (back-pressure); tie it high otherwise.

`aes128_iter`: a block is taken when `in_valid && in_ready`; `out_valid`
pulses ten clocks later with `out_block`, which holds until the next result.
`in_ready` is high again in the clock the result is produced, so blocks can
follow each other every ten clocks.

Blocks and keys are 128-bit vectors in FIPS-197 byte order: byte 0
(`in0`, `key0`) is bits `[127:120]`.

## Running

Needs Icarus Verilog, Python 3, and optionally Verilator and Yosys
(Ubuntu: `apt-get install iverilog verilator yosys`).

```
cd Verilog
make test           # 206 + 100 vectors through both cores (TEST PASSED)
make test NVEC=2000 SEED=5
make lint           # verilator -Wall, clean
make synth          # Yosys synth_xilinx LUT/FF per core
make selftest       # aes_ref.py against FIPS-197 / SP 800-38A
```

`make test` checks every vector against its expected ciphertext, the
latency (10), the throughput (iterative: 10 clocks/block, pipeline: N blocks
in N + 10 clocks), and result order under random input gaps and clock-enable
stalls with a different key on every block.
